# @wardic/dom

The browser environment for [Wardic](https://wardic.dev): its clock on `requestAnimationFrame`, the renderer that writes styles, pointer, keyboard and focus input, the probe that reads the page, and the projection system behind layout animations, as Effect Layers.

[`@wardic/solid`](https://www.npmjs.com/package/@wardic/solid) brings it; install it yourself only to build a binding of your own.
