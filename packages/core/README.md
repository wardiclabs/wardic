# @wardic/core

Wardic's animation engine, on [Effect](https://effect.website): springs, tweens, inertia and keyframes, variants, the projection geometry behind layout animations, and the services an environment provides (a clock, a renderer, input, a probe).

Most apps don't install it directly: they use a binding, [`@wardic/solid`](https://www.npmjs.com/package/@wardic/solid), which brings it. It's for building an environment or a binding of your own.
