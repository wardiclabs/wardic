# Variants

A variant is a named target. An element lists them in `variants`, and `initial`, `animate`, `exit` and the `while*` props name one. Its children with `variants` of their own follow the same names, each with its own target, spaced out by the parent's transition.

## Children follow

A child with `variants` that names none of its own (no name on `initial`, `animate`, a `while*` prop or `exit`) starts from its parent's `initial` and follows its `animate`, as in Motion. A child that names one, such as `whileHover="hover"`, keeps its own: it follows no name from above, and takes no stagger slot. On a server-rendered page, every child arrives at its `initial` already, so the entrance starts from there with no flash. An element in between, without `variants`, passes the names through; `inherit={false}` keeps a child out.

## Orchestration

The parent's transition times its children:

- `staggerChildren: 0.05` starts each child 50 ms after the one before.
- `delayChildren` waits before the first, or with `stagger(0.07, { from, startDelay, ease })`, decides each child's whole delay: `from: "last"` runs them back to front.
- `when: "beforeChildren"` or `"afterChildren"` runs the parent's own animation first or last.

## Custom, and lists of names

A variant can be a function of `custom`, so each child computes its own target:

```tsx
const item = { open: (i: number) => ({ opacity: 1, transition: { delay: i * 0.1 } }) }
<w.li variants={item} custom={index()} />
```

`animate={["visible", "active"]}` names more than one: they merge in order. And a gesture can name a variant too, `whileHover="hover"`, which the children follow as they follow `animate`.
