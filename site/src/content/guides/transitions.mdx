# Transitions

`transition` says how an element gets to its target: a spring, a tween, or keyframes on the way. Press Move and the three take the same trip their own way.

## Springs

A spring is set by its physics, `stiffness`, `damping` and `mass`, or by time:

- `{ type: "spring", duration: 0.5, bounce: 0.25 }` lands on its target at 0.5 s. `bounce` is 0.3 unless you give one.
- `{ visualDuration: 0.5, bounce: 0.25 }` does most of its move in 0.5 s, then settles. `bounce` is 0 here.

A spring keeps the velocity it's handed: retarget one mid-flight, or release a drag into it, and it carries on from there. With no `type`, any spring field (`stiffness`, `damping`, `mass`, `bounce`, `visualDuration`) makes a spring.

## Tweens

A tween runs for `duration` seconds along `ease`: one of Motion's names (`"easeOut"`, `"easeInOut"`, `"backOut"`, `"anticipate"`…), a cubic Bézier's four numbers (`[0.25, 0.1, 0.35, 1]`), or a function. The functions are exported by the same names: `import { easeOut, cubicBezier, steps } from "@wardic/solid"`.

## Keyframes

A target that's a list plays through its stops: `animate={{ x: [0, 200, 160] }}`. `times` places each stop between 0 and 1, and `ease` can be a list, one per stretch. A first stop of `null` is wherever the value is now.

## Per value

A value can have a transition of its own, under its name, with `default` for the rest:

```tsx
<w.div animate={{ x: 100, opacity: 1 }} transition={{ default: { type: "spring" }, opacity: { duration: 0.2 } }} />
```

`delay` waits before it starts, and `repeat`, `repeatType` (`"loop"`, `"reverse"`, `"mirror"`) and `repeatDelay` play it again.

## At the end

`transitionEnd` sets values once the target's own have landed, such as hiding a panel after it fades:

```tsx
<w.div animate={{ opacity: 0, transitionEnd: { display: "none" } }} />
```

## With no transition

Each value runs on Motion's default for it: `x`, `y` and `rotate` on a spring, `scale` on a stiffer one, and everything else, opacity and colours among them, on a 0.3 s ease. A `WardicConfig` sets one for every element below it: `<WardicConfig transition={{ type: "spring", bounce: 0.2 }}>`.
