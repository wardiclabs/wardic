# useIsPresent

Whether a child of an [`AnimatePresence`](/reference/solid/presence/animate-presence) is still present: `false` from its leave on, while its exit plays. Its own effects and bindings have ended by then, so a binding such as `disabled={!present()}` never sees `false`: it's for what still runs on the element, an event handler or a timer. To act as the child leaves, use [`usePresence`](/reference/solid/presence/use-presence)'s `next("leave")`. Motion's `useIsPresent`.

On Solid 2, it's given to `ref`, and called to read:

```tsx
import { useIsPresent } from "@wardic/solid"

const present = useIsPresent()
<button ref={present} onClick={() => present() && save()}>Save</button>
```

On Solid 1, it takes the child's element, or an accessor of it:

```tsx
import { useIsPresent } from "@wardic/solid/v1"

let el!: HTMLButtonElement
const present = useIsPresent(() => el)
<button ref={el} onClick={() => present() && save()}>Save</button>
```

Outside a presence, always `true`.

## Types

- **`IsPresent`:** (Solid 2) what it returns: called with an element, it attaches to it; with nothing, it reads.
