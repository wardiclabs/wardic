# VERSION

**Solid 1 only,** from the deprecated `@wardic/solid/v1`. The version of `@wardic/solid` in use, as a string: for a bug report, or a check in a tool.

```ts
import { VERSION } from "@wardic/solid/v1"

console.log(VERSION) // its package.json's version, such as "2.0.0"
```

The root, Solid 2's binding, has none: read your lockfile, or `@wardic/solid`'s `package.json`.
