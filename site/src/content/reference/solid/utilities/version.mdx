# VERSION

The version of `@wardic/solid` in use, as a string: for a bug report, or a check in a tool.

```ts
import { VERSION } from "@wardic/solid"

console.log(VERSION) // its package.json's version, such as "1.0.0"
```

Solid 1 only: on Solid 2, read your lockfile, or `@wardic/solid`'s `package.json`.
