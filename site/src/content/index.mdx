# Animation for Solid

Wardic gives [Solid](https://www.solidjs.com) the API of [Motion](https://motion.dev) for React: elements that animate (`initial`, `animate`, `exit`, `transition`), variants that pass down the tree, hover, press, focus, drag and pan, layout and shared-element animations, presence, and values that follow the scroll or the pointer.

On a server-rendered page, mount animations play before the JavaScript has loaded, and the client takes them over mid-flight. And each page ships only the animation code it uses.

- **Fast where motion happens:** retargets, unmounts and each running frame in about half of Motion's time or less.
- **Motion's API, the Solid way:** a `w.div` takes what a `motion.div` takes, with the Features its Wardic instance gives.
- **Built on Effect:** replace parts of its engine, with [Environments beyond the DOM](/roadmap#15-beyond-the-dom) planned.

[Why Wardic](/why) has the numbers, and what it costs.

```tsx
import { DomLive } from "@wardic/dom"
import { createWardic, domAnimation, WardicProvider } from "@wardic/solid"

// An app's Wardic instance, in a module of its own (src/lib/wardic.ts): hover, press, focus and in-view.
const { w } = createWardic(domAnimation)

export function App() {
  return (
    <WardicProvider env={DomLive}>
      <w.div initial={{ opacity: 0, y: 12 }} animate={{ opacity: 1, y: 0 }} whileHover={{ scale: 1.05 }}>
        Hello
      </w.div>
    </WardicProvider>
  )
}
```
