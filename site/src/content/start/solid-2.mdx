# Start on Solid 2

Wardic's binding for Solid 2 is `@wardic/solid/unstable/v2`: the same elements and animation props as Solid 1's, built on Solid 2's reactivity. Where Solid 1 takes Motion's callback props, such as `onTap`, Solid 2 tells the same moments as a ward's events: give the element a ward, `<w.button wardRef={card}>`, and `onTap` is `await card.next("tap")`. See [Ward events](/reference/solid/elements/ward-events). It stays outside semver until Solid 2 itself is stable.

## The provider

Every Wardic element sits under one `WardicProvider`. It takes the environment Wardic runs in, `DomLive` in a browser, and the **Features** its elements have: `domAnimation` is hover, press, focus and in-view.

```tsx
import { DomLive } from "@wardic/dom"
import { domAnimation, WardicProvider } from "@wardic/solid/unstable/v2"

export default function App() {
  return (
    <WardicProvider env={DomLive} features={[domAnimation]}>
      <Page />
    </WardicProvider>
  )
}
```

## Your first element

A `w.*` element animates from `initial` to `animate`, and back as its state changes:

```tsx
import { w } from "@wardic/solid/unstable/v2"

export function Card() {
  return <w.div initial={{ opacity: 0, y: 12 }} animate={{ opacity: 1, y: 0 }} whileHover={{ scale: 1.03 }} />
}
```

## Only what a page uses

A page that drags or lays out brings `drag` or `layout` itself, through `LazyWardic`, so the pages that don't never load them:

```tsx
import { drag, LazyWardic, w } from "@wardic/solid/unstable/v2"

export function Board() {
  return (
    <LazyWardic features={[drag]}>
      <w.div drag />
    </LazyWardic>
  )
}
```
