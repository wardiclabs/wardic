# Start on Solid 2

Wardic's binding for Solid 2 is `@wardic/solid/unstable/v2`: the same elements and animation props as Solid 1's, built on Solid 2's reactivity. Where Solid 1 takes Motion's callback props, such as `onTap`, Solid 2 tells the same moments as a ward's events: give the element a ward, `<w.button wardRef={card}>`, and `onTap` is `await card.next("tap")`. See [Ward events](/reference/solid/elements/ward-events). It stays outside semver until Solid 2 itself is stable.

## The provider

Every Wardic element sits under one `WardicProvider`. It takes the environment Wardic runs in: `DomLive` in a browser.

```tsx
import { DomLive } from "@wardic/dom"
import { WardicProvider } from "@wardic/solid/unstable/v2"

export default function App() {
  return (
    <WardicProvider env={DomLive}>
      <Page />
    </WardicProvider>
  )
}
```

## Your app's Features

What an element does beyond animating its values, a gesture, layout or a colour space, is a [Feature](/guides/features), code a page ships only if it asks for it. Choose your app's once, in a module of their own: `domAnimation` is hover, press, focus and in-view.

```tsx
// src/lib/wardic.ts
import { createWardic, domAnimation } from "@wardic/solid/unstable/v2"

export const { w } = createWardic(domAnimation)
```

Import `w` from it, not from the binding. Its elements take those Features' props, and its wards hear their events: a prop or an event of another is a type error that names it. These guides import it as `~/lib/wardic.ts`, SolidStart's alias for `src`; in a plain Vite app, import it by its path.

## Your first element

A `w.*` element animates from `initial` to `animate`, and back as its state changes:

```tsx
import { w } from "~/lib/wardic.ts"

export function Card() {
  return <w.div initial={{ opacity: 0, y: 12 }} animate={{ opacity: 1, y: 0 }} whileHover={{ scale: 1.03 }} />
}
```

## Only what a page uses

A page that drags or lays out makes an instance of its own, in a module only its pages import, so the pages that don't never load `drag` or `layout`:

```tsx
// src/lib/wardic-drag.ts
import { createWardic, domAnimation, drag } from "@wardic/solid/unstable/v2"

export const { w } = createWardic([domAnimation, drag])
```

[Shipping less](/guides/features) has the rest: loading a Feature later, and the sections a `LazyWardic` makes.
