`StageValues` (#934): the values a Stage's Subjects take beyond an element's, for a ward's config on one, which an Environment adds to by declaration merging, as it adds its Subjects to `StageSubjects`. With `@wardic/three/solid`, `ward(mesh, { animate: { roughness: 0.2, clearcoat: 1, emissive: "#ff6a00" } })` typechecks: a material's, a light's and a camera's numbers and colours, as three's `animate` takes them. A name in neither is still an error naming it. `StageValueKey` is their names.
